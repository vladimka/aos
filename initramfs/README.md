# initramfs — содержимое встроенной ФС

Всё, что лежит в этой папке, при сборке (`make`) упаковывается в newc cpio
архив (`/boot/initramfs.img` на ISO) и при загрузке распаковывается в корень
SFS-файловой системы ОС (с семантикой *write-if-absent*: уже существующий
файл не перезаписывается, чтобы сохранить правки на постоянном диске).

Просто положи сюда файл или папку — и после `make` (+ запуска) он появится
в ОС на том же пути. Примеры:

- `etc/init.conf` — конфиг системы инициализации (`/etc/init.conf`);
- `demo.ico` — демо-иконка на рабочем столе;
- `sys/config.cfg` — если положишь сюда, перекроет значения по умолчанию
  (тема, обои, часовой пояс);
- любой свой файл/папка — окажется в корне `/`.

Технические детали: архив собирается `scripts/gen_progs.py --tree initramfs`,
unpack – `kernel/initramfs.c`. Программы `bin/*` и `lin/*` доупаковываются
отдельно из собранных ELF, их сюда класть не нужно.
