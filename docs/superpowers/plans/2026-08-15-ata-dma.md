# План: Bus Master DMA для ATA-драйвера

Дата: 2026-08-15
Спека: `docs/superpowers/specs/2026-08-15-ata-dma-design.md`

## Обзор

DMA (BM IDE, read+write) прозрачно заменяет PIO-цикл в многосекторных операциях
`ata_read_multi`/`ata_write_multi` (count >= 2). Завершение — опросом BM-статуса,
без IRQ. При отсутствии BM или ошибке — фолбэк на PIO в блок-слое. Все шаги идут
в `main`; тесты — `atatest.py` + регрессия `blktest.py`/`make test-fast`.
