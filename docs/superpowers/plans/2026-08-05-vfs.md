# Hierarchical VFS + SFS2 (kernel and Linux-ABI) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat SFS (`kernel/sfs.c`, 64-entry, 1 MiB at `0x300000`) with a hierarchical virtual filesystem: an on-disk **SFS2** format (512 B blocks, 256 inodes, block bitmap, directories-as-files), a **VFS** layer (mount table, inode cache with refcounts, open-file table, per-task fd table and CWD), a read-only **procfs**, and one fd-based API shared by the AOS syscalls and the Linux ABI (dropping the `fd_name`/`fd_off` emulation in `kernel/linux_syscall.c`). The Linux ABI additionally gains `chdir`/`getcwd`/`mkdir`/`rmdir`/`getdents64`/`stat64` so static musl `ls` works.

**Architecture:** A new `kernel/block.c` provides sector I/O behind a unified device interface (`struct sdev`: RAM backend over the old 1 MiB FS buffer at `0x300000`, and a vblk adapter over virtio-blk) plus a write-back 512 B sector cache with pinning. `kernel/sfs2.c` is the on-disk format: superblock + 256×48 B inode table + block bitmap + directories stored as files of 32 B entries; metadata (inode table + bitmap) is always-resident and flushed with the cache. `kernel/vfs.c` owns the mount table (`/` = SFS2, `/proc` = procfs), path resolution (`.`/`..`, absolute/relative, O_CREAT auto-mkdir -p), inode cache, open-file table, and the fd API. `kernel/procfs.c` is a read-only pseudo filesystem. `kernel/syscall.c` swaps the flat `SYS_FS_*` syscalls for `SYS_OPEN..SYS_UNLINK`. `kernel/linux_syscall.c` reuses the same fds. Old `kernel/sfs.c` and `kernel/fs.h` are deleted.

**Tech Stack:** C (GCC `-ffreestanding -m32 -std=c11`, no libc, only `kernel/string.c`), x86 32-bit protected mode, existing buddy allocator (`page_alloc`/`kmalloc`), RTC (`drivers/rtc.h` `rtc_get()` for mtime), QEMU 10.2.1, Python headless boot test harnesses (serial-socket + monitor).

## Global Constraints

- No libc. Compiled `-ffreestanding -nostdlib -fno-builtin -fno-stack-protector -mno-sse -mno-mmx -mno-80387`. Include paths `-Ikernel -Idrivers -Iarch/i386 -Iboot`. Use `__asm__ __volatile__`, never `asm` (C11).
- Paging identity-maps 0..256 MB (physical == virtual); page-table pointers/addresses are usable directly. Everything (kernel, pages, kmalloc, block cache) stays **below `0x08000000`** — Linux tasks re-point PDE 32..63 (`0x08000000..0x10000000`) at private user page tables (`kernel/pmm.c` reserve + comments).
- The old SFS RAM buffer region `0x300000..0x400000` stays reserved in `pmm.c` — it is now the RAM backend's 1 MiB block device (`SFS2` in RAM mode).
- `kernel/printf.c`/`serial_print*` for kernel banners. `extern volatile unsigned int tick;` (1000 Hz) for timeouts.
- Errors are negative errnos: `-2` ENOENT, `-5` EFAULT (bad user pointer), `-9` EBADF, `-16` EBUSY, `-17` EEXIST, `-20` ENOTDIR, `-21` EISDIR, `-22` EINVAL, `-24` EMFILE (fd table full), `-28` ENOSPC, `-39` ENOTEMPTY. Valid user pointer must pass `in_user`/`in_user_area` (user area `0x01000000..0x01804000` plus slab window `0x03000000..0x04000000`); `copy_user_str_alloc()` (copies + NUL) for paths.
- Syscalls are dispatched from `struct regs` (`eax=n`, `ebx..edi` = args). **Next free syscall number is 36** (`kernel/syscall.h` currently has 0..35). Flat `SYS_FS_*` (4–9) are **removed** (their numbers are not reused; existing 0–35 keep their numbers).
- `programs/libaos.c` mirrors syscall numbers with local `#define`s and a 6-arg `syscall()` via `int $0x80`; programs are `-ffreestanding` and cannot include kernel headers.
- `kernel/progs.c` is generated by `scripts/gen_progs.py` (programs stored as `bin/<name>`, data as `--data name=path`) — never edit by hand; embedded payload is seeded into the new FS in both RAM and disk modes (only when absent).
- Boot order in `kernel/kernel.c`: `... -> interrupts_init -> ... -> fs_init -> config_load -> load_embedded_programs -> load_embedded_data -> terminal_init -> hlt`. `vfs_init()` (mount + seed) replaces the `fs_init`/`load_embedded_*` trio. `virtio_init()` (with `sfs_set_disk`) runs earlier and is replaced by a `block` backend hand-off.
- Existing RAM-mode tests boot the ISO **without** a disk — the FS must work with the RAM backend and no virtio-blk.
- `make` is idempotent; keep `.SECONDARY` in the Makefile. Spec: `docs/superpowers/specs/2026-08-05-vfs-design.md`.

## Task 1: Block layer — `struct sdev` backends + pinned sector cache

**Files:**
- Create: `kernel/block.h`, `kernel/block.c`
- Modify: `drivers/virtio.c` (`sfs_set_disk(...)` → `block_set_disk(...)`), `kernel/pmm.c` (comment only, region already reserved), `Makefile` (add `kernel/block.o`)
- Create: `scripts/blockself.py` (optional boot trace check)

**Interfaces:**
- Consumes: `vblk_present`/`vblk_read`/`vblk_write`/`vblk_capacity_bytes` (`drivers/vblk.h`), `FS_MEM`-equivalent RAM buffer, `memcpy`/`memset`.
- Produces:
  - `struct sdev { int (*read)(unsigned int lba, void *buf); int (*write)(unsigned int lba, const void *buf); int present; unsigned int capacity_sectors; };`
  - `int block_init(void)` — picks RAM or disk backend, logs `block: ram backend, 2048 sectors` / `block: disk backend, N sectors`.
  - `unsigned char *block_pin(unsigned int lba)` — returns a pointer to the sector (from cache or read-through), marks it non-evictable.
  - `void block_unpin(unsigned int lba)`
  - `void block_flush(void)` — writes all dirty sectors to the sdev, clears dirty bits.
  - `int block_disk_present(void)`
- Backends: `sdev_ram` (1 MiB static buffer at `0x300000`, 2048 sectors, `read`/`write` = memcpy) and a `sdev_vblk` adapter (present only when `vblk_present()`).

- [ ] **Step 1: Create `kernel/block.h`**

```c

#define BLOCK_H

#define BLOCK_CACHE_SECTORS 128

    unsigned int capacity_sectors;
};

void block_unpin(unsigned int lba);
void block_flush(void);

#endif
```

- [ ] **Step 2: Create `kernel/block.c`**

Structure: a static 128-entry cache (`sector[BLOCK_CACHE_SECTORS][512]`, `lba[]`, `dirty[]`, `pin[]`, `last_used[]` for FIFO/LRU eviction), plus the chosen sdev. `block_pin` returns a live pointer; evicts a clean unpinned entry when full (never a pinned one). `block_flush` writes every dirty entry whose sector is valid. RAM backend uses `0x300000` (constant `SFS_BASE` from old `kernel/sfs.h`; keep a local `#define RAMDISK_BASE 0x300000` and `RAMDISK_SECTORS 2048`). Initialize `block_init` to pick the backend and print a banner.

```c
#include "block.h"
#include "vblk.h"
#include "serial.h"
#include "string.h"

#define RAMDISK_BASE 0x300000
#define RAMDISK_SECTORS 2048

static struct sdev *dev;
static unsigned char cache[BLOCK_CACHE_SECTORS][BLOCK_SIZE];
static unsigned int cache_lba[BLOCK_CACHE_SECTORS];
static unsigned char cache_dirty[BLOCK_CACHE_SECTORS];
static unsigned char cache_pin[BLOCK_CACHE_SECTORS];
static unsigned char cache_valid[BLOCK_CACHE_SECTORS];

static int sdev_ram_read(unsigned int lba, void *buf) {
    memcpy(buf, (void *)(RAMDISK_BASE + lba * BLOCK_SIZE), BLOCK_SIZE);
    return 0;
}
static int sdev_ram_write(unsigned int lba, const void *buf) {
    memcpy((void *)(RAMDISK_BASE + lba * BLOCK_SIZE), buf, BLOCK_SIZE);
    return 0;
}

static int sdev_vblk_read(unsigned int lba, void *buf) { return vblk_read(lba, buf); }
static int sdev_vblk_write(unsigned int lba, const void *buf) { return vblk_write(lba, buf); }
```

(Eviction/search helpers `find_slot`, `evict`, `load_sector`; `block_pin` → `load_sector` if not valid → set `pin`; `block_unpin` clears the bit; `block_flush` iterates dirty && valid, `dev->write`, clears dirty.)

- [ ] **Step 1: Define the on-disk layout in `kernel/sfs2.h`**

```c
#ifndef SFS2_H
#define SFS2_H

#define SFS2_MAGIC0 'S'
#define SFS2_MAGIC1 'F'
#define SFS2_MAGIC2 'S'
#define SFS2_MAGIC3 '2'

#define SFS2_INODES 256
#define SFS2_INODE_SIZE 48
#define SFS2_INDIRECT_BLOCKS 128          // 512/4
#define SFS2_MAX_FILE_BLOCKS (8 + SFS2_INDIRECT_BLOCKS)
#define SFS2_DIRENT_SIZE 32
#define SFS2_DIRENTS_PER_BLOCK (512 / SFS2_DIRENT_SIZE)   // 16
#define SFS2_NAME_MAX (SFS2_DIRENT_SIZE - 4)              // 28

#define SFS2_TYPE_FREE 0
#define SFS2_TYPE_FILE 1
#define SFS2_TYPE_DIR  2

struct sfs2_super {
    char magic[4];
    unsigned int version;          // 1
    unsigned int block_count;
    unsigned int inode_count;      // SFS2_INODES
    unsigned int inode_start;      // block 1
    unsigned int bitmap_start;     // block 1 + inode_table_blocks
    unsigned int data_start;       // bitmap_start + bitmap_blocks
    unsigned int root_inode;       // 1
};

struct sfs2_inode {
    unsigned char type;
    unsigned char pad0;
    unsigned short nlink;
    unsigned int size;
    unsigned int mtime;
    unsigned int direct[8];
    unsigned int indirect;         // 0 = none
    unsigned char pad1[3];         // total 48 bytes
};

struct sfs2_dirent {
    unsigned int ino;              // 4 bytes
    char name[SFS2_NAME_MAX + 1];  // 28 bytes (SFS2_NAME_MAX = 27 chars + NUL)
};                                 // total exactly 32 bytes

struct sfs2_fs {
    unsigned int block_count;
    unsigned int inode_start, bitmap_start, data_start;
    unsigned int root_inode;
    unsigned int inode_blocks, bitmap_blocks;   // derived at mount
};

int sfs2_init(struct sfs2_fs *fs);
int sfs2_format(struct sfs2_fs *fs);
int sfs2_selftest(void);
/* inode / dir / data ops as above */
#endif
```

`struct sfs2_dirent` is exactly 32 bytes (`ino` 4 + `name[28]`), so 16 fit per block. `SFS2_NAME_MAX = 27`.

- [ ] **Step 2: Create `kernel/sfs2.c`**

Static always-resident metadata buffers: `static unsigned char inode_mem[SFS2_INODES * SFS2_INODE_SIZE];` and `static unsigned char bitmap_mem[64];` (covers up to 512 blocks; bump to 512 bytes for large disks — a 4 MiB disk has 8192 blocks, so bitmap = 1024 bytes). Layout math at mount:
- `inode_blocks = (SFS2_INODES * SFS2_INODE_SIZE + 511) / 512` (= 24)
- `bitmap_start = 1 + inode_blocks`
- `data_start = bitmap_start + bitmap_blocks` where `bitmap_blocks = (block_count - data_start + 4095) / 4096` (blocks coverable per 512 B bitmap sector)
- Pin `[inode_start .. data_start)` permanently via `block_pin`; keep the returned pointers.

Data path: `read_at` walks `direct[8]` then the `indirect` block (read the 128-pointer block into a 512 B scratch via `block_pin`/`block_unpin`). `write_at` allocates missing blocks with `alloc_block()` (first free bit in the bitmap), marks inode dirty; `truncate` frees blocks beyond the new size, sets bitmap. Every mutation ends with `block_flush()` when the disk backend is present (RAM backend flush is a no-op memcpy, harmless). `nlink` increments on `add_dirent`/`mkdir`, decrements on remove; `unlink` frees the inode when `nlink == 0`. `mtime` set from `rtc_get()`-derived epoch seconds (helper `fs_time_now()` in sfs2.c, later exposed via vfs).

## Self-review notes

- **Spec coverage:** block layer (Task 1), SFS2 format core (Task 2), VFS + mounts + inode cache + open-file table + kernel migration (Task 3), fd syscalls + program migration (Task 4), per-task fds/cwd + shell builtins (Task 5), Linux ABI on real fds with dir/stat syscalls (Task 6), procfs + persistence tests (Task 7), cleanup/docs/regression (Task 8).
- **Backward compatibility:** RAM mode = the old 1 MiB buffer at `0x300000` under the same block API; embedded programs/config/demo.ico are re-seeded write-if-absent; `configtest.py`, `notepadtest.py`, `ipctest.py`, `manytest.py` keep passing; WM desktop icons unchanged.
- **EBUSY semantics:** `vfs_inode.refcount` counts open-file handles; `unlink`/`rmdir` return `-16` when `refcount > 0`. `dup` bumps the open_file refcount, not the inode's.
- **Linux ABI:** console fds 0/1/2 are pseudo-files (write → `terminal_write`, read → `read_key`), matching today's `write(1/2)` behavior; musl `ls`/`cat` need nothing beyond the implemented syscalls (`opendir` → `open(O_DIRECTORY)` + `getdents64`; `access` → stat).
- **Allocation safety:** block cache, sfs2 metadata, and vfs structs are kmalloc'd or static — all below `0x08000000`, so Linux tasks' remapped window never collides with them.
