# План: AHCI/SATA бэкенд для блок-слоя

Дата: 2026-08-15
Спека: `docs/superpowers/specs/2026-08-15-ahci-design.md`

## Обзор

Новый диск-бэкенд `ahci` (QEMU `ich9-ahci`) рядом с `ata`/`vblk`: синхронный
AHCI-драйвер (командный лист slot 0, PRDT/DMA, polling `PxCI`/`PxIS`, без IRQ/NCQ),
интеграция в `kernel/block.c` с приоритетом `ahci > ata > vblk > ram`. Заодно чинится
дефект пункта 2 (multi-слоты не назначались для `ata`/`vblk` в `block_init`). Все шаги
идут в `main`; тесты — новый `ahcitest.py` + регрессия `atatest.py`/`blktest.py`/
`persisttest.py`/`make test-fast`.
